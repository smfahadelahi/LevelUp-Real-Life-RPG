# Privacy Notes — Current MVP

The current MVP is designed to store player progress, quests, and habit check-ins locally in the app's Room database.

The current source does not implement account registration, cloud synchronization, advertising, analytics, or third-party tracking SDKs. If these capabilities are added later, this document and the Play Store privacy disclosures must be updated before release.

Users should be able to reset or delete their locally stored progress in a future settings screen. That control is not yet implemented.
