# LEVELUP — Real Life RPG

**Your Life. Your Game. Your Level.**

Native Android personal-growth RPG built with Kotlin and Jetpack Compose.

## Current MVP foundation
- Dark RPG-inspired dashboard
- Daily quest cards and one-time in-session XP claims
- XP rewards and level progression
- Five character attributes
- Habits checklist and bottom navigation

## Stack
Kotlin · Jetpack Compose · Material 3 · Gradle Kotlin DSL · JUnit

## Run
Open this repository in Android Studio, sync Gradle, then run the `app` configuration on an emulator or device.

## Roadmap
Room persistence, DataStore preferences, reminders, streak history, achievements, accessibility/UI tests, and optional cloud/social features.

## Product principles
Reward consistency, allow rest, avoid shame-based streaks, and keep progress user-controlled.
